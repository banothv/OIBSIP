# EDA on Retail Sales Data

## Oasis Infobyte SIP – Data Analytics Internship

**Task:** Level 1 – Task 1: Exploratory Data Analysis on Retail Sales Data

## Project Overview

This project performs Exploratory Data Analysis (EDA) on retail sales data using Python. The objective is to understand customer purchasing behaviour, sales trends, product categories and business performance.

## Dataset

- **Dataset:** Customer Shopping Dataset – Retail Sales Data
- **Source:** [Kaggle – Customer Shopping Dataset](https://www.kaggle.com/datasets/mehmettahiraslan/customer-shopping-dataset)
- **File:** `retail_sales_dataset.csv`

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

1. Data inspection and cleaning
2. Descriptive statistical analysis
3. Monthly and quarterly sales trends
4. Customer age and gender analysis
5. Product and category revenue analysis
6. Correlation heatmap
7. Additional business insights and visualizations

## Business Recommendations

Recommendations are based on the findings from the actual dataset:

1. Improve inventory planning based on high-revenue product categories.
2. Investigate lower-performing categories to identify opportunities for improvement.
3. Use customer purchasing patterns to plan targeted marketing campaigns.

## Project Files

- `EDA_Retail_Sales.ipynb` – Complete analysis and visualizations.
- `retail_sales_dataset.csv` – Kaggle dataset.
- `requirements.txt` – Required Python libraries.

## Conclusion

This project demonstrates how exploratory data analysis can help businesses understand sales performance, customer behaviour and opportunities for improvement.
